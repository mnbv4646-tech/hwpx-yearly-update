# 최종 보고 형식

사용자는 결과 파일을 한글로 열기 전에 이 보고를 읽고 어디를 볼지 정한다. 짧고 구체적으로 쓴다.

```
[파일 이름].hwpx 를 만들었습니다. 블록 N개를 모두 갱신했고, 자가 검증 오류는 0건입니다.

1. 블록별 변경
| 블록 | 주요 숫자 (올해 / 증감률) | 표 구성 변경 |
| ... | 세입 18억 6천만원 (△11.23%), 세출 72억 3천1백만원 (9.94%) | 신규사업 2건 → 3건, 감액사업 표 새로 넣음 |

2. 적용한 기준
- 규칙 파일: (적용한 항목)
- 작년 관례를 따른 것: (예: 부서별 "보다/대비" 문체)
- 기본값을 쓴 것: (예: 증감률 반올림)

3. 사람이 확인할 곳
- [검토 필요] N곳: (블록과 내용 한 줄씩, 많으면 블록별 개수)
- 근거를 못 찾아 비운 곳:

4. 발견한 불일치
- 작년 문서: (예: 금액 문장 "9억 9천만원"은 표 기준 9억 9천3백만원)
- 원자료: (예: 목차의 문화관광체육국 109쪽은 실제 409쪽)

5. 검증
- 남은 [확인] 항목과 정상으로 본 이유
- 렌더링으로 확인한 쪽

6. 한글에서 열어 볼 곳
- 행 수를 바꾼 표: (블록, 표 이름)
```
