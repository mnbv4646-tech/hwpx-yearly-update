# 기본값 (규칙 파일이 없거나 비어 있는 항목)

먼저 작년 문서에서 관례를 읽고, 관례도 분명하지 않을 때 아래를 쓴다. 기본값을 쓴 항목은 최종 보고에 적는다.

| 항목 | 기본값 | 근거 |
|---|---|---|
| 숫자 단위 | 표에 적힌 단위 그대로 (천원, 백만원) | |
| 감소 표시 | △ | 작년 문서 관례를 따름 |
| 증감률 | 소수 둘째 자리, 반올림 | 예산서 자체가 반올림을 씀 (예: 9.8789% → 9.88). 실제 예비심사보고서도 반올림 286곳, 버림 52곳 |
| 전년 0인 증감률 | "-" | 작년 문서에 "순증" 등 다른 표기가 있으면 그것 |
| 문장 속 금액 | 백만원 단위 반올림 ("18억 6천만원"), 백만원 미만은 만원 | 작년 문장의 띄어쓰기, 표기 방식(62백만원 등) 유지 |
| 기정예산액, 전년도 예산액, 전년 본예산 | 원자료의 전년도 예산액 | |
| 쪽번호 칸 | 원자료 아래쪽에 인쇄된 쪽번호 | PDF 쪽번호가 아님 |
| 연도 | 제목, 표 머리, 짧은 소제목만 한 해 올림 | 사업 기간, 과거 이력 연도는 그대로 |
| 신규사업 | 보조 자료(설명자료)에 "신규" 표시가 있으면 그것. 없으면 전년도예산액이 0인 세부사업만 | 편성목, 통계목, 산출근거 단위로 처음 보이는 것은 애매하므로 문서에 올리지 않고 최종 보고에 "신규 후보"로. 올릴 것이 없으면 " : 해당없음" (후보가 있었으면 `[검토 필요]`) |
| 증액, 감액 사업 | 작년 문서의 건수와 단위를 따라 증감액이 큰 순 | 기준을 보고서에 적음 |
| 사업개요, 편성사유 | 산출근거와 보조 자료에 있는 사실만. 칸의 소제목과 항목 줄은 작년 칸 그대로 | 기간, 위치, 대상을 모르면 줄은 남기고 값 자리에 [검토 필요]. 판단 근거나 메모는 문서에 넣지 않고 최종 보고에 |
| 검토의견 서술 | 작년 문체를 따라 초안, 판단이 들어간 문장은 [검토 필요] | 사람이 최종 판단 |
