# 규칙 파일 양식

사용자가 일상 언어로 쓰는 업무 기준이다. 대화에 `규칙.md` 로 올리거나 프로젝트 지침에 넣는다. 결과에서 틀린 곳이 보이면 요청문이 아니라 이 파일을 고친다.

## 빈 양식

```markdown
# 문서 규칙: [문서 이름]

## 문서 정보
- 문서 이름:
- 블록 단위: (예: 부서별, 장별)

## 원자료
- 숫자의 근거:
- 보조 자료와 쓰는 곳:
- "쪽번호" 칸에 넣을 것:

## 숫자
- 단위:
- 감소 표시:
- 증감률: (자리수, 반올림 또는 버림)
- 전년이 0일 때 증감률 칸:

## 문장
- 금액 표기:
- 비교 표현: (보다 / 대비)

## 목록 표 선정
- 신규사업: (판단 기준, 단위: 세부사업 / 편성목 / 산출근거)
- 증액, 감액 사업: (단위, 최소 차이, 건수, 건수를 블록마다 셀지 과마다 셀지)
- 행정운영경비(인건비, 기본경비)를 목록에 넣을지:
- 그 밖의 목록 표:

## 사람이 쓰는 부분
-

## 하지 말 것
-
```

## 예시: 예산안 예비심사보고서

```markdown
# 문서 규칙: 예산안 예비심사보고서 (문화복지환경위원회)

## 문서 정보
- 문서 이름: 2026년도 예산안 예비심사보고서
- 블록 단위: 부서 ("○○ 소관" 제목 상자가 블록의 시작)

## 원자료
- 예산서 PDF: 숫자의 유일한 근거
- 예산 설명자료: 사업개요, 신규 여부, 증감 사유의 근거 (없으면 [검토 필요])
- "예산서페이지" = 예산서 아래쪽 인쇄 쪽번호

## 숫자
- 단위: 표에 적힌 단위 그대로 (천원 또는 백만원)
- 감소 표시: △
- 증감률: 소수 둘째 자리, 반올림 (표 안에 % 기호는 쓰지 않음)
- "기정예산액", "전년도 예산액" = 예산서의 전년도예산액

## 문장
- 금액: "18억 6천만원"처럼 백만원 단위 반올림
- 비교 표현: 부서별 작년 문체 유지 (보다 / 대비)

## 목록 표 선정
- 신규사업: 설명자료의 "신규" 표시 기준. 설명자료가 없으면 전년도예산액이 0인 세부사업만. 편성목 이하에서 처음 보이는 것은 문서에 넣지 않고 최종 보고에 "신규 후보"로
- 증액, 감액 사업: 편성목 단위, 차이 1천만원 이상, 과마다 상위 5건 (해당 없는 과의 표는 "해당없음")
- 행정운영경비: 목록에 넣지 않음

## 사람이 쓰는 부분
- 검토의견: 초안만. 의견과 추정은 모두 [검토 필요]

## 하지 말 것
- 원자료에 없는 기간, 위치, 대상, 법적 근거를 지어내지 않기
```
