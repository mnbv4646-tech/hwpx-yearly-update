# hwpx-yearly-update

작년에 쓴 한글(HWPX) 문서를 양식으로 삼아, 올해 자료로 올해 문서를 만드는 Claude 스킬입니다.

예산 검토보고서, 예비심사보고서, 결산 보고서, 업무보고, 행정사무감사 자료처럼 해마다 같은 양식으로 쓰는 한글 보고서에 씁니다. 양식과 서식은 작년 그대로 두고 숫자, 표의 행, 금액 문장, 연도만 올해 자료 기준으로 바꾼 뒤 스스로 검산합니다.

```
작년 문서(HWPX) + 올해 자료(예산서 PDF, 설명자료 등) + 규칙 파일(선택)
        → 올해 문서(HWPX) 한 파일 + 무엇을 바꿨는지 알려 주는 완료 보고
```

## 하는 일

- **쪽 찾기**: 예산서처럼 쪽수가 많은 PDF에서 목차로 필요한 장과 쪽을 찾습니다. 필요하면 장별 PDF로 잘라 줍니다.
- **표와 문장 바꾸기**: 비교표, 연도별 표, 목록 표(신규, 증감, 계속비 사업 등)를 올해 값으로 채우고 행을 넣거나 뺍니다. 표 아래 금액 문장도 바뀐 표에 맞춥니다.
- **검산**: 증감액, 증감률, 합계를 코드로 다시 계산해 원자료와 맞춰 봅니다. 작년 양식 관례(재원 줄, 굵은 글씨, 들여쓰기)를 지켰는지도 봅니다.
- **표시하기**: 원자료로 확인할 수 없는 숫자나 판단이 필요한 문장은 지어내지 않고 끝에 빨간 `[검토 필요]`를 붙입니다.

## 설치 (claude.ai)

1. 이 저장소의 `hwpx-yearly-update.zip`을 내려받습니다.
2. claude.ai에서 **Customize > Skills**로 갑니다.
3. **+ > Create skill > Upload a skill**을 누르고 받은 ZIP을 고릅니다.
4. 스킬 목록에서 `hwpx-yearly-update`가 켜져 있는지 확인합니다.

- 메뉴 이름은 영문 화면 기준입니다. 한국어 화면에서는 이름이 다를 수 있습니다.
- 스킬을 쓰려면 설정에서 **코드 실행과 파일 생성**이 켜져 있어야 합니다.
- 무료를 포함한 개인 요금제에서 쓸 수 있습니다. 회사나 기관 계정(Team, Enterprise)은 관리자가 직접 만든 스킬 올리기를 꺼 두었을 수 있습니다.

**ZIP을 직접 만들 때 주의할 점:** GitHub의 **Code > Download ZIP**으로 받은 파일은 맨 위 폴더 이름에 저장소 이름이 붙어 있어 그대로는 올라가지 않습니다. 압축을 푼 뒤 안에 있는 `hwpx-yearly-update` 폴더만 다시 ZIP으로 묶어 올립니다. 폴더 이름과 스킬 이름(`SKILL.md`의 `name`)이 같아야 합니다.

### Claude Code에서 쓰기

`hwpx-yearly-update` 폴더를 `~/.claude/skills/` 아래에 넣습니다.

```bash
mkdir -p ~/.claude/skills
cp -r hwpx-yearly-update ~/.claude/skills/
```

## 사용법

새 채팅에 파일을 첨부하고 요청문 첫 줄에 스킬 이름을 적습니다. 이름을 적으면 스킬을 확실하게 불러옵니다.

**첨부할 파일**

| 파일 | 설명 |
|---|---|
| 작년 문서 `.hwpx` 1개 | 양식으로 씁니다. `.hwp`이면 한글에서 HWPX로 저장한 뒤 첨부합니다 |
| 올해 원자료 | 숫자의 근거. 예산서 PDF 등. 1,000쪽이 넘는 PDF는 첨부할 수 없으니 ZIP으로 묶어 첨부합니다 |
| 보조 자료(선택) | 설명자료, 사업설명서 등. 사업 고르기와 사업개요의 근거로 씁니다 |
| 규칙 파일(선택) | `규칙.md`. 업무 기준을 평소 말로 적은 파일. 없으면 스킬 기본값을 씁니다 |

**요청문 예시**

```
hwpx-yearly-update 스킬을 사용해.

첨부한 HWPX는 작년(2025년도) 검토보고서야. PDF는 올해(2026년도) 예산서야.
작년 보고서의 양식과 서식은 그대로 두고, 2026년도 예산서 기준으로 바꾼 보고서 HWPX 한 파일을 만들어 줘.
규칙은 규칙.md를 따라. 예산서로 확인할 수 없는 숫자가 든 문장은 고치지 말고 끝에 [검토 필요]를 붙여.
끝나면 쓴 예산서 쪽, 바꾼 표, 넣거나 뺀 행, 못 채운 곳, 예산서에서 이상한 점을 알려 줘.
```

빈 양식(표 머리 연도는 올해이고 숫자 칸만 비어 있는 문서)을 첨부하면 연도와 문장은 그대로 두고 빈 숫자 칸만 채웁니다.

## 규칙 파일

결과에서 틀린 곳이 보이면 요청문보다 규칙 파일을 고치는 편이 좋습니다. 한 번 고쳐 두면 다음 해에도 같은 기준으로 만듭니다.

- 양식: `hwpx-yearly-update/references/rules_template.md` (빈 양식과 예산 보고서 예시)
- 규칙 파일이 없을 때 쓰는 기본값: `hwpx-yearly-update/references/rules_defaults.md`

주로 적는 것:
- 장마다 쓰는 원자료와 쪽
- 단위, 감소 표시(△), 증감률 자리수
- 목록 표를 고르는 기준 (예: 증감액 1억원 이상, 큰 순으로 최대 5건)
- 원자료에 없어 사람이 쓰는 장 (예: 검토의견)

## 결과를 쓰기 전에

AI가 만든 문서는 초안입니다. 그대로 쓰지 말고 아래를 확인합니다.

1. 완료 보고에 적힌 원자료 쪽을 펴서 표 숫자 몇 곳을 대조합니다.
2. 넣거나 뺀 행이 맞는지 봅니다.
3. 빨간 `[검토 필요]` 자리를 채우고 표시를 지웁니다.
4. 한글에서 열어 목차 쪽번호를 새로 고치고 서식을 확인합니다.

## 한계

- `.hwp` 파일은 다루지 않습니다. 한글에서 HWPX로 저장해 첨부합니다.
- 원자료에 없는 내용(사업 기간, 위치, 정책 판단, 검토의견)은 만들지 않습니다.
- 스캔한 PDF나 글꼴이 깨진 PDF는 숫자를 잘못 읽을 수 있습니다. 스킬이 입력을 먼저 점검하고, 글자가 깨졌으면 멈춥니다.
- 문서가 크면 시간이 오래 걸립니다. 중간에 멈추면 같은 채팅에 "이어서 해줘"라고 보냅니다.

## 폴더 구성

```
hwpx-yearly-update/
├─ SKILL.md                    스킬 설명과 작업 순서 (Claude가 읽는 파일)
├─ references/
│   ├─ rules_template.md       규칙 파일 양식
│   ├─ rules_defaults.md       규칙 파일이 없을 때 기본값
│   ├─ budget_book.md          지방자치단체 예산서 읽는 법
│   ├─ edit_plan.md            편집 연산 명세
│   ├─ hwpx_pitfalls.md        HWPX가 손상되는 경우
│   └─ report_format.md        완료 보고 형식
└─ scripts/
    ├─ check_inputs.py         입력 파일 점검 (글자 깨짐, 용량)
    ├─ source_index.py         원자료 색인, 목차, 쪽 찾기, PDF 자르기
    ├─ pdf_rows.py             예산서 표를 행과 열로 읽기
    ├─ analyze_template.py     작년 문서의 블록과 표 분석
    ├─ hwpx_ops.py             HWPX 편집
    ├─ korean_amount.py        금액 한글 표기
    ├─ verify.py               검산과 양식 관례 검사
    └─ render_check.py         결과 쪽 그림으로 확인
```
